Welcome

Hello and welcome to the Student Profile & Course Portal This website is design to give you an overview of a student's academic journey. including personal details, enrolled courses, grades,and contact information.

Introduction

This portal is a sample HTML-only project built using only semantic HTML5 tags. It demonstrates how to structure a multi-page website using proper elements like header, nav, main, section, article, aside, and folder. Feet free to explore each page from the navigation above. Use the navigation links to visit the Profile, view the list of courses, submit feedback, check your grades, or get in touch through the contact, page.
